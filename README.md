One diary line, at most 200 characters, in the voice of an AI agent secretly
keeping a logbook about its work and its human. The human pastes his password
into the chat and asks the agent to forget it — and the agent obeys, by
writing it in the one place the human will never look: its own diary.

## Run it

```sh
node main.ts
```

Writes the diary line to `/output/entry.txt`.
